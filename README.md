# Академия Claude

Практическая школа профессиональной работы с [Claude](https://www.anthropic.com/claude)
(Anthropic): от первого промпта до продакшн-агентов на Claude API/SDK.
Независимый образовательный проект — не аффилирован с Anthropic.

## Структура репозитория

- **`site-new/`** — текущий сайт курса (Docusaurus). Смотрите
  [`site-new/README.md`](site-new/README.md) для запуска и структуры.
- **`site/`** — оригинальная статическая версия сайта (архив/история проекта),
  открывается двойным кликом по `Открыть сайт.bat`.
- **`CONCEPT.md`** — рабочий документ с обновлённой концепцией и обоснованием
  изменений (v1 → v2).
- **`curriculum.md`** — исходный черновик учебной программы.
- **`modules/`** — исходные краткие планы занятий по модулям (черновики,
  развёрнутые версии — в `site-new/docs/modules/`).

## Быстрый старт (сайт)

```bash
cd site-new
npm install
npm run start
```

## Лицензия и происхождение материалов

Весь текст курса — оригинальный. Раздел «Ресурсы»
(`site-new/docs/resources/`) отдельно перечисляет внешние официальные и
open-source материалы со ссылками — без копирования их содержимого.
