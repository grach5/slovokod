# Модуль 3. Работа с документами

**Поток**: все | **Длительность**: 4 занятия по 90 мин | **Пререквизиты**: Модуль 0

## Цели модуля

Студент умеет создавать и редактировать Word/Excel/PowerPoint/PDF через Claude,
понимает границы автоматизации (что требует подтверждения перед отправкой/публикацией)
и способен собрать сквозной сценарий «данные → анализ → документ клиенту».

---

## Занятие 1: Word (.docx)

- Генерация документа с нуля: структура, заголовки, TOC
- Работа с шаблонами (.dotx), фирменный стиль
- Найти-и-заменить, вставка/замена изображений
- Работа с отслеживаемыми изменениями и комментариями

**Практика**: сгенерировать отчёт по заданной структуре с TOC и таблицей.

## Занятие 2: Excel (.xlsx)

- Очистка «грязных» данных: разъехавшиеся заголовки, мусорные строки
- Формулы и вычисляемые поля
- Графики и сводные таблицы
- Конвертация между табличными форматами (csv/tsv/xlsx)

**Практика**: взять неструктурированный csv-файл, превратить в чистую таблицу с
формулами и графиком.

## Занятие 3: PowerPoint (.pptx)

- Презентация из готовых данных/отчёта
- Работа с шаблонами и layout'ами
- Спикерские заметки, комментарии
- Разбиение/объединение презентаций

**Практика**: собрать презентацию на 6-8 слайдов из отчёта, сделанного на занятии 2.

## Занятие 4: PDF и сквозной сценарий

- Извлечение текста и таблиц из PDF, в т.ч. сканов (OCR)
- Слияние, разбиение, повороты страниц, watermark
- Заполнение форм, шифрование/дешифрование
- Сквозной кейс: данные (xlsx) → анализ → презентация (pptx) → PDF клиенту

**Практика**: собрать полный сценарий — от сырых данных до финального PDF-отчёта.

**Важно проговорить**: отправка готового документа клиенту/на email — это
действие, требующее явного подтверждения студента-«владельца» сценария на каждом
реальном запуске, автоматизация не должна сама решать, кому и когда отправлять.

---

## Итоговый проект модуля

Автоматизировать создание еженедельного отчёта: вход — сырые данные (csv/xlsx),
выход — презентация или PDF с графиками, готовый к отправке (без реальной отправки
на этом этапе).

## Критерии проверки

- [ ] Итоговый документ корректно открывается в соответствующем приложении
- [ ] Данные очищены и не содержат артефактов исходного файла
- [ ] Презентация/отчёт использует единый визуальный стиль
- [ ] Студент может объяснить, какой шаг сценария потребовал бы подтверждения перед
      реальной отправкой
