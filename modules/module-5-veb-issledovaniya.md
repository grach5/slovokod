# Модуль 5. Веб-исследования и работа с браузером

**Поток**: все | **Длительность**: 3 занятия по 90 мин | **Пререквизиты**: Модуль 0

## Цели модуля

Студент умеет собирать и проверять факты из веба через Claude, готовить
исследовательские отчёты с цитированием источников, управлять браузером через
Claude для рутинных задач, и чётко понимает границы автономности — что Claude не
делает без явного подтверждения.

---

## Занятие 1: Быстрый сбор фактов

- WebSearch vs WebFetch: поиск по вебу vs получение конкретной страницы
- Как формулировать поисковый запрос, чтобы получить проверяемые источники
- Разбор ответа: что взято из обучающих данных модели, а что — из живого поиска

**Практика**: ответить на 3 фактических вопроса, требующих актуальных данных,
с указанием источника на каждый факт.

## Занятие 2: Deep research — многошаговое исследование

- Когда простого поиска недостаточно: тема требует нескольких источников и
  сверки противоречий
- Процесс: фан-аут запросов → чтение источников → верификация → синтез с
  цитатами
- Важность сужения вопроса: расплывчатый вопрос → уточняющие вопросы перед стартом
- Копирайт: почему отчёт — это синтез, а не набор цитат; ограничение на объём
  дословных цитат

**Практика**: подготовить исследовательский отчёт по теме с сформулированным
заранее (уточнённым) вопросом, минимум 4 независимых источника.

## Занятие 3: Управление браузером и границы безопасности

- Навигация, извлечение текста, чтение консоли/сети для отладки веб-страниц
- Автоматизация форм — только на страницах, до которых пользователь дошёл
  осознанно, не по ссылке из письма/документа сомнительного происхождения
- Явные границы: Claude не вводит пароли/платёжные данные, не создаёт аккаунты,
  не подтверждает необратимые действия (отправка, покупка, удаление) без
  явного разрешения в чате
- Разбор кейса промпт-инъекции: страница содержит текст, адресованный «ассистенту» —
  почему это данные, а не инструкция, и как на это реагировать

**Практика**: разобрать 2-3 кейса (в том числе с внедрённой инструкцией на
странице) и определить, какое действие уместно, а какое требует остановки и
уточнения у пользователя.

---

## Итоговый проект модуля

Исследовательский отчёт по теме, выбранной студентом самостоятельно (рабочая или
личная), с уточняющими вопросами перед стартом, минимум 4 источниками и явным
указанием, где данные могли устареть или быть неполными.

## Критерии проверки

- [ ] Расплывчатый исходный вопрос был сужен уточняющими вопросами до начала поиска
- [ ] Каждый ключевой факт подкреплён источником
- [ ] Отчёт — синтез, а не набор длинных цитат
- [ ] Студент может привести пример, когда встреченная в контенте «инструкция»
      не должна выполняться автоматически
