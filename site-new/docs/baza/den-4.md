## Зачем это

До сегодня сайт видели только вы. Он лежал на вашем компьютере.
Друг не может открыть файл на вашем диске. Работодатель — тоже.
Сегодня у сайта появится ссылка. Её можно отправить в мессенджер.
Её можно открыть с телефона, из любой точки мира.

## Что вы сделаете

Опубликуете сайт и получите рабочую ссылку.
Проверите, что сайт открывается на телефоне и обновляется после правок.

## Главное правило

**Публикация одностраничного сайта — это перетаскивание папки, а не программирование.** Терминал (окно для текстовых команд) не нужен. Установка программ не нужна. Есть сервисы, которые принимают папку с сайтом прямо в браузере: перетащили — через секунды получили адрес.

## Теория

Сервис публикации — это место в интернете, куда можно "положить" папку с файлами, и она станет сайтом, доступным по ссылке. В этом дне используется Netlify Drop (netlify.app/drop) — можно опубликовать первый сайт вообще без регистрации, просто перетащив папку в окно браузера.

Такой сервис ищет в папке файл с именем **index.html**. Это главная страница сайта, "входная дверь". Если файла с этим именем нет, сервис не поймёт, что показывать, и покажет список файлов вместо сайта.

Адрес, который вы получите, будет техническим — вида `имя.сервис.app`. Он не такой короткий и красивый, как обычный домен (адрес вида `сайт.ру`), но полностью рабочий. Свой домен можно подключить позже, когда сайт уже проверен и работает.

Обновление сайта — это повторное перетаскивание той же папки. Адрес при этом не меняется: ссылка, которую вы уже отправили, продолжит вести на сайт, только с новым содержимым.

Бесплатного тарифа таких сервисов достаточно для учебного и личного сайта — платить не нужно.

## По шагам

1. Откройте папку с сайтом и убедитесь, что главный файл называется именно `index.html`. Вы должны увидеть: файл с этим именем в корне папки.
2. Проверьте, что в папке нет лишних файлов — черновиков, копий, файлов вида `index-1.html`. Вы должны увидеть: в папке только файлы, нужные сайту.
3. Откройте app.netlify.com/drop в браузере — регистрация не нужна. Вы должны увидеть: область с надписью, куда перетащить папку.
4. Перетащите папку с сайтом в это окно. Вы должны увидеть: индикатор загрузки или процесс обработки.
5. Дождитесь появления адреса и откройте его в браузере. Вы должны увидеть: ваш сайт, открытый по новой ссылке.
5а. Без бесплатной регистрации сайт исчезнет примерно через сутки — нажмите «Claim» (забрать) на странице результата и заведите бесплатный аккаунт, чтобы ссылка осталась навсегда. Вы должны увидеть: сайт привязан к вашему аккаунту, кнопка «Claim» больше не появляется.
6. Отправьте ссылку себе в мессенджер и откройте её с телефона. Вы должны увидеть: тот же сайт, открытый на экране телефона.
7. Если на телефоне сайт выглядит криво, попросите Claude адаптировать код (промт ниже), замените код и перетащите папку заново. Вы должны увидеть: на телефоне текст читается без увеличения, кнопки нажимаются пальцем.
8. Внесите любую небольшую правку в текст сайта и перетащите папку ещё раз. Вы должны увидеть: изменение появилось по той же самой ссылке.

## Готово к копированию

```
Сделай так, чтобы страница нормально выглядела на телефоне: ничего не разъезжается, текст читается без увеличения, кнопки нажимаются пальцем. Внешний вид на компьютере не меняй. Выдай готовый код одним блоком.
```

## Типичные ошибки

- По ссылке открывается список файлов → главный файл назван не `index.html` → переименуйте файл и опубликуйте заново.
- В папке остались `index-1.html`, `index-2.html` → это случайные копии → удалите их перед публикацией.
- На телефоне сайт разъезжается → вы проверяли сайт только на широком экране компьютера → откройте сайт с телефона и попросите Claude адаптировать вёрстку.
- Сайт исчез через сутки → не нажали «Claim» и не завели бесплатный аккаунт после публикации → опубликуйте заново и сразу нажмите «Claim».
- Вы сразу пытаетесь купить свой домен → это преждевременный шаг → сначала убедитесь, что сайт работает на техническом адресе.

## Задание и критерии приёмки

- [ ] Сайт опубликован и открывается по ссылке
- [ ] Ссылка открывается с другого устройства (например, с телефона)
- [ ] Сайт корректно выглядит на телефоне: текст читается, кнопки нажимаются
- [ ] После повторного перетаскивания папки правка появилась на сайте
- [ ] В папке сайта нет черновиков и лишних копий файлов
- [ ] Вы помните адрес сайта без подсказки

## Если не получилось

- Открывается список файлов вместо сайта → главный файл называется не `index.html` → переименуйте и опубликуйте заново.
- Сайт пропал через сутки после публикации → не нажали «Claim» → загрузите папку снова и сразу заведите бесплатный аккаунт по кнопке «Claim».
- Стили (оформление) не применились → CSS-код лежит отдельным файлом и не попал в папку при перетаскивании → попросите Claude собрать весь код в один файл `index.html` и опубликуйте заново.
- Ссылка не открывается на телефоне → проверьте интернет-соединение на телефоне и перепроверьте саму ссылку на опечатки.
