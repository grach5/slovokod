---

Одиннадцать модулей, от основ промптинга до проверки качества и безопасности
многоагентных систем — бесплатный бонусный трек, который открывается после
трека «Полная». Каждый модуль заканчивается мини-проектом, который попадает
в портфолио.

Не все модули требуют программирования: M0, M3, M4, M5 работают через
обычный чат на claude.ai. M1, M2, M2.5, M6, M8 требуют Claude Code
(инструмент для работы с кодом через терминал). M7 и M9 рассчитаны на тех,
кто пишет код сам. Столбец «Требует» в таблице ниже показывает, что нужно
для каждого модуля — можно проходить по порядку или пропускать модули не
по вашему профилю.

:::tip[Первый раз здесь?]
Прежде чем открывать Модуль 0, прочитайте [«С чего начать»](./s-chego-nachat) —
одна страница о том, что такое Claude, где его открыть и что означают базовые
термины. Две минуты, и дальше все модули понятны без пропущенных шагов.
:::

Модули идут по порядку сложности (M0 → M9) — при первом прохождении открывайте
их по номерам, начиная с [«С чего начать»](./s-chego-nachat) и Модуля 0. К уже
пройденным модулям возвращайтесь как к справочнику: нужная тема, нужная
практика, без необходимости читать всё заново.

| № | Модуль | Что внутри | Требует |
|---|--------|-----------|-------|
| M0 | [Основы промптинга](./module-0-osnovy-promptinga) | Как Claude «думает», выбор модели под задачу, анатомия сильного промпта, разбор типичных галлюцинаций. | claude.ai |
| M1 | [Claude Code — разработка](./module-1-claude-code) | Навигация по чужому коду, безопасные правки, тесты, git, code-review, subagents и workflows. | Claude Code |
| M2 | [Автоматизация и агенты](./module-2-avtomatizaciya-agenty) | MCP-серверы, scheduled tasks, /loop, многоагентные workflow — pipeline vs parallel. | Claude Code |
| M2.5 | [Токены, память и контекст](./module-2t-tokeny-pamyat-kontekst) | Паттерн memory-bank, компактный CLAUDE.md, промпт-кэширование, выбор модели по бюджету. | Claude Code |
| M3 | [Работа с документами](./module-3-dokumenty) | Word, Excel, PowerPoint, PDF — от очистки данных до готового отчёта клиенту. | claude.ai |
| M4 | [Аналитика и визуализация данных](./module-4-analitika-vizualizaciya) | Выбор формы графика, дашборды, публикация артефакта в светлой и тёмной теме. | claude.ai |
| M5 | [Веб-исследования и работа с браузером](./module-5-veb-issledovaniya) | Сбор фактов из интернета, многошаговые исследования, границы автономности агента. | claude.ai |
| M6 | [Артефакты и мини-приложения](./module-6-artefakty) | Публикация интерактивных страниц, диаграммы, runtime-возможности прямо со страницы. | Claude Code |
| M7 | [Claude API / SDK для разработчиков](./module-7-api-sdk) | Messages API, tool use, prompt caching, Agent SDK, мультимодальность, выбор модели. | Свой код |
| M8 | [Интеграции и экосистема](./module-8-integracii) | Claude в Slack, IDE-расширения, MCP-реестр, Desktop/Web/CLI — когда что уместно. | Claude Code |
| M9 | [Проверка качества и безопасность](./module-9-kachestvo-bezopasnost) | Eval-наборы, независимая верификация, безопасность многоагентных систем. | Свой код |

Столбец «Требует» показывает не тариф, а инструмент: «claude.ai» — обычный
чат в браузере, «Claude Code» — терминальный инструмент (ставится в
Модуле 1), «Свой код» — уверенное владение языком программирования.

Хотите, чтобы Claude отвечал клиентам прямо на вашем сайте или в боте, а не
только через ручной чат на claude.ai? Это и есть Модуль 7 — но писать код
можете не вы: модуль подходит и для того, чтобы понимать, что делает
нанятый программист. Если такой интеграции не планируется — M7 и M9 можно
смело пропустить.

Дополнительные материалы для практики — в разделе [«Ресурсы»](/docs/resources/resursy):
шаблоны, библиотека промптов, карта официальных и открытых репозиториев по Claude.
