---

Одиннадцать модулей, от основ промптинга до проверки качества и безопасности
многоагентных систем. Каждый модуль соответствует одному из трёх потоков —
**Старт**, **Практик** или **Инженер** — и заканчивается мини-проектом, который
попадает в портфолио.

Не уверены, какой вы поток? Сначала посмотрите сравнение на странице
[«Программа»](/programma) — там за 30 секунд можно определить свой, прежде
чем смотреть колонку «Поток» ниже. Коротко: **Старт** — без кода, **Практик** —
плюс автоматизация и агенты, **Инженер** — плюс API/SDK для разработчиков.

:::tip[Первый раз здесь?]
Прежде чем открывать Модуль 0, прочитайте [«С чего начать»](./s-chego-nachat) —
одна страница о том, что такое Claude, где его открыть и что означают базовые
термины. Две минуты, и дальше все модули понятны без пропущенных шагов.
:::

Модули идут по порядку сложности (M0 → M9) — при первом прохождении открывайте
их по номерам, начиная с [«С чего начать»](./s-chego-nachat) и Модуля 0. К уже
пройденным модулям возвращайтесь как к справочнику: нужная тема, нужная
практика, без необходимости читать всё заново.

Колонка «Поток» показывает, для какого потока модуль обязателен по программе.
Модули без вашего потока в списке необязательны для вас, но открыты для
чтения — просто могут опираться на знания из модулей, которые в вашем потоке
пропущены. Как именно порядок и доступ к модулям зависят от зачисления в
поток — смотрите на странице [«Программа»](/programma).

Дополнительные материалы для практики — в разделе [«Ресурсы»](/docs/resources/resursy):
шаблоны, библиотека промптов, карта официальных и открытых репозиториев по Claude.
