Эта страница — то, что обычно объясняют на первой живой встрече, но что
обязательно нужно и тому, кто читает модули самостоятельно. Пять минут — и
дальше все модули будут понятны без пропущенных шагов.

## Что такое Claude

Claude — это ИИ-модель (искусственный интеллект) компании Anthropic, с которой
можно переписываться на обычном языке: попросить объяснить, написать,
посчитать, найти. Технически это называется **LLM** (Large Language Model,
«большая языковая модель») — программа, обученная предсказывать продолжение
текста на основе огромного объёма примеров. Отсюда и её сильные, и слабые
стороны — подробнее в [Модуле 0](./module-0-osnovy-promptinga).

Курс делится на три потока — [«Старт», «Практик» и «Инженер»](/programma):
они отличаются набором модулей и глубиной погружения. Дальше на этой странице
слова «поток «Старт»» и т. п. означают именно это деление.

## Где открыть Claude

Claude — не одна программа, а несколько продуктов. Курс использует три:

| Продукт | Что это | Где используется в курсе |
|---|---|---|
| **[claude.ai](https://claude.ai)** (веб и приложение) | Обычный чат в браузере или на телефоне — переписка, документы, Artifact (см. словарь ниже) | Модули 0, 3, 4, 5, 6 — всё, что не требует терминала |
| **Claude Code** | Инструмент, который выполняет задачи через терминал, работая прямо с файлами проекта — не только для программистов | Модули 1, 2, 2.5 (поток «Практик»/«Инженер») |
| **Claude API / [консоль Anthropic](https://console.anthropic.com)** | Программный доступ по API-ключу, без готового интерфейса чата | Модуль 7 (только поток «Инженер») |
| **Расширения** (Slack, IDE — редактор кода, например VS Code) | Claude встроен в другие рабочие инструменты | Модуль 8 |

Для потока **«Старт»** достаточно [claude.ai](https://claude.ai) — регистрация
занимает пару минут. Это модули 0, 3, 4, 5 (4 модуля потока «Старт» — Модуль 6
тоже работает через claude.ai, но входит только в потоки «Практик»/«Инженер»,
смотрите [программу](/programma) для точного состава). Для **«Практик»/«Инженер»**
дополнительно понадобится Claude Code — как его установить, показано в начале
[Модуля 1](./module-1-claude-code). Для Модуля 9 (поток «Инженер») хватает
Claude Code или claude.ai — отдельного доступа он не требует.

## Бесплатно или платно

У [claude.ai](https://claude.ai) есть бесплатный и платные тарифы — лимиты и
цены меняются, актуальные условия смотрите на [claude.ai](https://claude.ai),
а не в этом курсе. Курс не включает подписку на Claude — это отдельная вещь:
курс учит пользоваться инструментом, а не продаёт доступ к нему.

Для потоков «Старт» и «Практик» бесплатного тарифа claude.ai обычно
достаточно. Для «Инженер» с Модуля 7 понадобится платный доступ к Claude
API — оплата по токенам, отдельно от стоимости курса (подробнее — в начале
[Модуля 7](./module-7-api-sdk)).

## Мини-словарь

- **Промпт** — ваше сообщение модели: вопрос, задача, инструкция.
- **Чат** — одна переписка с Claude от начала до конца; модель помнит всё
  внутри чата, но по умолчанию не помнит ничего из других чатов (подробнее —
  в [Модуле 0](./module-0-osnovy-promptinga)).
- **Контекст** — весь текст, который модель «видит» при ответе: ваш промпт,
  приложенные файлы, история переписки.
- **Artifact** — отдельная страница или мини-приложение, которое Claude может
  опубликовать по вашей просьбе (см. [Модуль 6](./module-6-artefakty)).
- **Агент** — режим, в котором Claude не просто отвечает текстом, а сам
  выполняет шаги: ищет в интернете, редактирует файлы, запускает команды
  ([Claude Code](./module-1-claude-code), Модуль 1 — как раз такой агент).
