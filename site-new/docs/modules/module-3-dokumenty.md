Claude создаёт и редактирует Word, Excel, PowerPoint и PDF напрямую — готовыми файлами, а не текстом в чате. Модуль ведёт от чистого листа до сценария «данные → анализ → документ клиенту».

**Файлы в чате**: чтобы приложить файл — нажмите на значок скрепки/плюса в поле ввода или перетащите файл в чат. Готовый файл от Claude появляется в чате карточкой — нажмите «Скачать», чтобы сохранить его на компьютер.

## Занятие 1: Word (.docx)

### Генерация отчёта с нуля

Промпт «напиши отчёт о продажах» работает плохо: Claude либо угадывает структуру, либо переспрашивает. Задавайте структуру явно:

```
Собери Word-документ «Итоги квартала: розничное направление».
Структура:
1. Титульный лист — название, квартал, дата, отдел
2. Автособираемое оглавление (TOC)
3. Резюме для руководителя — 3–4 абзаца
4. Динамика продаж по месяцам — таблица + вывод
5. Риски и рекомендации — маркированный список

Заголовки — тёмно-синий, Calibri, стили Heading 1/2 (для автосбора TOC).
```

Claude использует настоящие стили Word, поэтому оглавление кликабельно и обновляется при правках.

### Шаблоны и правки

Есть корпоративный `.dotx`? Загрузите его вместе с промптом — Claude заполнит данными, сохранит колонтитулы и логотип.

Частые правки:

- **Поиск-и-замена с учётом контекста** (find-and-replace): «замени "Ромашка" на "Восход", но не трогай раздел "История переименований"» — учитывается контекст, не слепая замена строки.
- **Замена изображений**: «замени логотип на титульном листе на `logo_2026.png`, сохранив размер и положение».
- **Комментарии**: «оставь комментарии там, где сроки оплаты двусмысленны» — это настоящие Word-комментарии, а не список в чате.

**Практика**: сгенерировать отчёт по структуре выше с TOC и таблицей на своей теме.

## Занятие 2: Excel (.xlsx)

### Очистка «грязных» данных

Выгрузки из CRM, 1С или Google Forms почти никогда не приходят чистыми:

**До** (сырой `export.csv`):
```
name,, revenue,, region
Иванов,,120000,, Москва
,, ,,
Петров,,98000,, СПб
петров п.,,98000,,спб
,, ,,
Сидорова,,ERR,, Казань
```

Промпт: «Выгрузка из CRM, колонки разъехались. Убери пустые строки и разделители, приведи регион к единому регистру, объедини дубликаты (Петров = петров п.), замени `ERR` на пропуск с пометкой "требует проверки"».

**После**:

| Имя | Выручка, ₽ | Регион | Комментарий |
|---|---|---|---|
| Иванов | 120 000 | Москва | |
| Петров | 98 000 | СПб | объединена дублирующая строка |
| Сидорова | — | Казань | требует проверки: исходное значение `ERR` |

Claude объясняет, что сделал с каждой аномалией — вы проверяете решение, а не доверяете вслепую.

### Формулы, сводные таблицы, графики

Плановые показатели по регионам обычно лежат на отдельном листе «План» (Регион | План, ₽) — на него ссылается формула ниже.

- **Вычисляемая колонка**: «"Выполнение плана, %" = факт / план, округли до одного знака, подсвети красным ниже 90%» — Claude пишет формулу (`=ROUND(B2/План!B2*100,1)`), таблица пересчитается сама.
- **Сводная таблица**: строки — регион, столбцы — месяц, значения — сумма выручки.
- **График**: линейный, линия на каждый регион — нативный Excel-график, а не картинка.

Между `csv` / `tsv` / `xlsx` Claude конвертирует, сохраняя типы: числа остаются числами.

**Практика**: превратить csv в чистую таблицу с вычисляемой колонкой, сводной таблицей и графиком.

## Занятие 3: PowerPoint (.pptx)

### Презентация из готового отчёта

Частый сценарий: «на основе `otchet_q3.docx` собери 7 слайдов — титул, резюме, графики, риски, рекомендации, контакты». Claude берёт цифры из документа, а не пересказывает заново.

### Шаблоны и заметки

Корпоративный `.potx` (шаблон PowerPoint, аналог `.dotx` для Word) — Claude заполняет его готовые макеты слайдов вместо оформления с нуля. Отдельно попросите заметки: «2–3 тезиса на слайд для устного комментария».

### Разбиение и объединение

- «Собери презентацию для инвесторов только из слайдов 1, 3, 5–7».
- «Объедини мою презентацию с блоком "О компании" из corporate-deck.pptx, сохранив моё оформление».

Claude старается согласовать шрифты между исходниками, но при слиянии презентаций из разных источников проверяйте итоговые слайды вручную.

**Практика**: собрать 6–8 слайдов из Excel-таблицы, собранной на занятии 2, с заметками хотя бы к трём слайдам.

## Занятие 4: PDF и сквозной сценарий

### Извлечение текста и таблиц, включая сканы

Из обычного PDF Claude достаёт текст и таблицы напрямую: «таблицу с ценами со страницы 4 — в Excel». Скан требует OCR (распознавание текста на изображении): «распознай счёт, вытащи номер, сумму и дату» — рукописный текст проверяйте вручную.

### Слияние, разбиение, повороты, watermark

- «Объедини три PDF в порядке: договор, приложение, счёт».
- «Раздели 40-страничный отчёт на файлы по главам».
- «Поверни страницы 5–8, они загружены боком».
- «Поставь водяной знак "Черновик" по диагонали».

### Заполнение форм, шифрование

«Заполни PDF-заявление данными из таблицы, по строке на человека» работает для PDF-полей и для форм-«картинок». Отдельно: «поставь» или «сними пароль» — для защиты перед отправкой вовне.

### Сквозной сценарий

1. **Вход**: сырой `sales_export.csv` с разъехавшимися колонками (как на занятии 2).
2. **Excel**: очистить, посчитать выполнение плана по регионам, сводная таблица и график.
3. **Презентация**: `.pptx` на 8 слайдов с графиками и заметками для встречи с клиентом.
4. **Финал**: экспорт в PDF, титульная страница с логотипом клиента, пароль перед передачей.

**Важно**: реальная отправка файла клиенту требует вашего явного подтверждения на каждом запуске. Автоматизация доводит документ до «готово к отправке» и останавливается там.

**Практика**: собрать все четыре шага — от сырых данных до финального PDF-отчёта с паролем.

## Итоговый проект модуля

Автоматизировать еженедельный отчёт: вход — сырые данные (`csv`/`xlsx`), выход — презентация или PDF с графиками, готовые к отправке (без реальной отправки). Опишите сценарий шагами: очистка → расчёт → визуализация → сборка — чтобы повторять его еженедельно, меняя только исходный файл.

## Критерии проверки

- [ ] Документ открывается в нужном приложении без ошибок и «битых» стилей
- [ ] Данные очищены от артефактов исходного файла (пустых строк, разъехавшихся колонок, дублей)
- [ ] Презентация/отчёт держит единый стиль от первой до последней страницы
- [ ] Формулы и графики в Excel пересчитываются при новых данных, а не «зашиты» числами
- [ ] Вы можете назвать шаг, требующий подтверждения перед отправкой клиенту
