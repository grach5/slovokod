## Зачем это

Вчера промт сработал с первого раза. Сегодня написали то же самое — и результат другой.
Кажется, что ассистент капризничает или у вас не получается объяснить задачу.
Из-за этого ощущения новички чаще всего бросают именно на второй день.
На самом деле никакой случайности нет. У поведения ассистента есть механика — три правила.
Сегодня вы их узнаете и перестанете гадать, почему «то работает, то нет».

## Что вы сделаете

Соберёте страницу-визитку одним промтом в Claude и внесёте в неё 3 изменения.
Результат: рабочий цикл «попросил → вставил → проверил», который будете использовать весь курс.

## Главное правило

**Ассистент не помнит вас и не понимает вашу задачу — он видит только текст, который сейчас перед ним, и продолжает его наиболее вероятным образом.** Это не собеседник, который держит вас в голове. Это система продолжения текста. Из этого правила следуют три механизма ниже — и почти все ошибки новичков.

## Теория

Из главного правила следуют три механизма.

**1. Контекст — рабочий стол, а не память.** Контекст — это тот текст переписки, который ассистент видит прямо сейчас. Диалог растёт, старые сообщения перестают в него помещаться. Поэтому важные требования повторяют заново в новом сообщении, а не считают сказанными «навсегда».

**2. Модель достраивает задачу, а не уточняет её.** Если в описании есть пробел — например, вы не указали цвет кнопки — ассистент не остановится и не спросит. Он заполнит пробел типичным вариантом, не обязательно тем, что вы имели в виду. Убирать неопределённость из задачи — ваша работа, а не его.

**3. Уверенный тон не означает правоту.** Ассистент может ровным, убедительным тоном назвать функцию или настройку, которой не существует. Текст ответа — не доказательство. Доказательство — проверка результата: запустили, посмотрели, сработало или нет.

Эти три пункта объясняют почти все «странности» первых дней работы с ассистентом. Дальше — практика: короткий цикл действий, который превращает эту теорию в рефлекс.

## По шагам

1. Откройте claude.ai и начните новый чат.
   Вы должны увидеть: пустое поле ввода, готовое принять текст.

2. Скопируйте промт из блока «Готово к копированию» ниже и отправьте его.
   Вы должны увидеть: ответ с одним блоком кода (HTML), без лишних объяснений.

3. На рабочем столе создайте папку с именем `den1`.
   Вы должны увидеть: новую пустую папку `den1`.

4. Включите показ расширений файлов (в Windows: «Вид» → «Расширения имён файлов»), затем создайте в папке `den1` пустой файл и назовите его `index.html` — именно так, не `index.html.txt`.
   Вы должны увидеть: файл `index.html` с иконкой браузера, а не блокнота.

5. Откройте `index.html` для редактирования, скопируйте код из ответа ассистента целиком и вставьте в файл, сохраните.
   Вы должны увидеть: файл сохранён, размер файла больше нуля.

6. Дважды щёлкните по `index.html`.
   Вы должны увидеть: страница-визитка открылась в браузере.

7. Сравните открывшуюся страницу с текстом промта: заголовок, строка про обучение, кнопка на месте.
   Вы должны увидеть: всё, что просили в промте, присутствует на странице.

8. Вернитесь в чат и напишите: «сделай кнопку крупнее и добавь под ней дату».
   Вы должны увидеть: новый блок кода с обновлённой версией страницы.

9. Замените содержимое `index.html` новым кодом, сохраните файл, вернитесь в браузер и нажмите F5.
   Вы должны увидеть: кнопка стала крупнее, под ней появилась дата.

## Готово к копированию

```
Сделай одностраничный сайт-визитку. Требования: один файл HTML, все стили внутри, без внешних библиотек; тёмный фон, светлый текст, одна колонка по центру; заголовок «Меня зовут [ИМЯ]», строка «Я учусь собирать продукты с ИИ», кнопка «Написать мне»; страница должна открываться двойным щелчком без установки чего-либо. Выдай только готовый код одним блоком, без объяснений.
```

## Типичные ошибки

- Файл не открывается в браузере, а открывается блокнот → настоящее расширение файла `.txt`, а не `.html` → включите показ расширений и переименуйте файл в `index.html`.
- В файл скопирован код вместе со служебными символами (например, тройные кавычки блока кода) → скопировано лишнее вокруг кода → копируйте только содержимое блока кода, без обрамления.
- Внесли правку, а на странице ничего не изменилось → файл не сохранён или страница не обновлена → сохраните файл заново, нажмите F5 в браузере.
- Просите «сделай красиво» и результат разочаровывает → у такого запроса нет проверяемого критерия → сравнивайте результат с текстом требований, а не с ощущением.
- Пытаетесь разобраться, как устроен код, уже на первом дне → это преждевременно → сегодня нужен только цикл «попросил → проверил», разбор кода — задача другого дня.

## Задание и критерии приёмки

- [ ] Собрана страница-визитка в файле `index.html`.
- [ ] Страница открывается двойным щелчком без установки программ.
- [ ] На странице есть заголовок, описание и кнопка.
- [ ] Внесено не менее 3 изменений по вашему выбору через промты.
- [ ] Вы можете своими словами назвать, что именно просили изменить на каждом шаге.
- [ ] Вы не открывали код, чтобы «разобраться», — это задача другого дня.

Сдаёте: скриншот готовой страницы.

## Если не получилось

- Ассистент выдал несколько отдельных файлов вместо одного → напишите: «собери всё в один файл HTML, стили внутри».
- Страница открылась, но она пустая → код скопировался не полностью → скопируйте код заново, целиком, включая первую и последнюю строку.
- Ответ ассистента оборвался на середине кода → у каждого ответа есть предел объёма — это ограничение сервиса, одинаковое для всех и не связанное с вашим компьютером → напишите: «продолжи с того места, где остановился».
- Хочется бросить, потому что не получается с первого раза → это нормально на первом дне курса → пройдите шаги ещё раз строго по порядку, не пропуская.
