## Зачем это

До сегодня проект открывался двойным щелчком мыши. Просто и понятно.
Но как только в проекте появляются данные или вход по паролю, так больше не получится.
Такой проект нужно запускать через терминал — окно, куда пишут текстовые команды.
Звучит пугающе. На деле нужных команд всего три.
Сегодня вы их освоите и перестанете бояться чёрного окна.

## Что вы сделаете

Запустите свой проект через терминал и откроете его в браузере по адресу localhost.
Научитесь останавливать и снова запускать проект самостоятельно.

## Главное правило

**Терминал — это то же самое окно с папками, только текстом.** Вы всегда находитесь внутри какой-то одной папки, даже если этого не видно. Девять из десяти ошибок новичка в терминале — это не поломка и не баг, а команда, выполненная не в той папке.

## Теория

Чтобы работать с терминалом, достаточно четырёх понятий.

**Терминал** — окно, куда вы печатаете команду и нажимаете Enter. На Windows это PowerShell или приложение «Терминал». На macOS — приложение «Терминал».

**Текущая папка** — папка, в которой сейчас «стоит» терминал. Перейти в другую папку — команда `cd` и путь к папке. Посмотреть, что лежит в текущей папке — команда `dir` на Windows или `ls` на macOS.

**Зависимость** (её ещё называют пакет) — это чужой готовый код, который использует ваш проект, чтобы не писать всё с нуля. Зависимости ставятся одной командой. Список нужных зависимостей хранится в файле `package.json`. Сам код зависимостей после установки лежит в папке `node_modules`. Эту папку не редактируют руками и не отправляют в репозиторий (хранилище версий кода, подробнее — в Дне 6).

**Переменная окружения** — значение, которое нельзя писать прямо в коде: пароль, ключ доступа. Хранится в отдельном файле `.env` рядом с проектом. Подробнее об этом — в Дне 10.

Дальше — практика: подготовить проект, открыть терминал, перейти в нужную папку, установить зависимости и запустить сайт.

## По шагам

1. Отправьте ассистенту (Claude) промт из блока «Готово к копированию» ниже. Вы должны увидеть: список файлов, их содержимое и точные команды для Windows и macOS.
2. Откройте терминал: на Windows нажмите Win, введите «Терминал», нажмите Enter; на macOS нажмите Cmd+Пробел, введите «Терминал», нажмите Enter. Вы должны увидеть: пустое окно с курсором и приглашением ввести команду.
3. Введите `cd`, поставьте пробел, затем перетащите мышкой папку проекта прямо в окно терминала — путь подставится сам. Нажмите Enter. Вы должны увидеть: в начале строки терминала — новый путь, путь до папки проекта.
4. Проверьте, что вы в нужной папке: введите `dir` на Windows или `ls` на macOS, нажмите Enter. Вы должны увидеть: файлы вашего проекта, например `package.json`.
5. Установите зависимости: введите `npm install`, нажмите Enter и дождитесь окончания. Вы должны увидеть: процесс завершился, и снова появилось приглашение ввести команду. Это может занять минуту.
6. Запустите проект: введите `npm run dev`, нажмите Enter. Вы должны увидеть: в терминале появился адрес вида `http://localhost:3000`.
7. Скопируйте этот адрес и откройте его в браузере. Вы должны увидеть: работающий сайт вашего проекта в браузере.
8. Не закрывайте окно терминала, пока пользуетесь сайтом. Вы должны увидеть: если случайно закрыть окно, сайт по адресу localhost перестаёт открываться — это ожидаемо, а не поломка.

## Готово к копированию

```
Подготовь мой проект к локальному запуску. Условия: самый простой возможный вариант, без лишних инструментов; в ответе дай: список файлов которые нужно создать, их содержимое, точные команды по порядку; команды дай отдельно для Windows и для macOS; объясни каждую команду одной строкой, без теории; если что-то нужно установить на компьютер — скажи прямо что именно и где взять с официального сайта.
```

## Типичные ошибки

- Терминал пишет «npm не распознана как команда» → не установлен Node.js → скачайте с сайта nodejs.org, затем закройте и заново откройте терминал.
- Команда `dir`/`ls` показывает не те файлы → команда выполнена не в той папке → посмотрите путь в начале строки, вернитесь `cd` в нужную папку.
- Закрыли терминал — сайт по localhost пропал → это не поломка → откройте терминал заново и введите `npm run dev`.
- Сообщение о занятом порте (port is already in use) → проект уже запущен в другом окне терминала → закройте лишнее окно или откройте адрес, который терминал предложил вместо занятого.
- Пытаетесь угадать причину ошибки и чинить наугад → так теряется время → скопируйте текст ошибки целиком и отдайте ассистенту, не пересказывая своими словами.

## Задание и критерии приёмки

- [ ] Проект запущен и открывается по адресу localhost в браузере
- [ ] Вы можете назвать, в какой папке сейчас стоит терминал
- [ ] Вы понимаете, зачем нужна папка `node_modules`, и не редактировали её вручную
- [ ] Вы умеете остановить проект и запустить его заново
- [ ] Каждую ошибку вы передавали ассистенту текстом, а не чинили угадыванием

## Если не получилось

- Терминал выдал много непонятных ошибок сразу → не пытайтесь разобрать все → скопируйте только самую первую ошибку сверху и отдайте её ассистенту.
- Установка зависимостей (`npm install`) идёт очень долго → дайте процессу 5 минут → если за это время он не закончился, нажмите Ctrl+C и запустите команду заново.
- Ничего не работает даже после часа попыток → создайте новую пустую папку и попросите ассистента собрать в ней минимальный проект с нуля → разбираться в уже сломанном проекте обычно дороже по времени.
- Не понятно, что означает адрес localhost:3000 → это адрес вашего же компьютера, доступный только вам → его нельзя отправить другу, для этого нужна отдельная публикация в интернете.
