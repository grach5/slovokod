Держите эту страницу открытой в отдельной вкладке в первые дни курса. Каждый термин объясняется один раз здесь — в уроках он не расшифровывается повторно.

## Работа с ассистентом

**Промпт** — ваше сообщение ассистенту: вопрос, задача, инструкция. То же самое, что вы обычно называете «написать в чат» — просто у этого действия есть отдельное слово, потому что о нём много говорят. «Скопируйте промпт» значит «скопируйте готовый текст и отправьте его ассистенту как сообщение».

**Чат** — одна переписка с ассистентом от начала до конца. Ассистент помнит всё внутри одного чата, но не помнит ничего из других чатов — это как разговор с человеком, который забывает вас, как только вы попрощались.

**Контекст** — весь текст, который ассистент «видит» в моменте ответа: ваш промпт, приложенные файлы, вся история переписки в этом чате. Есть предел, сколько текста туда помещается — подробнее в Дне 4 «Полной».

**Код-ревью** — проверка чужого кода построчно, обычно другим человеком или ассистентом: что в нём не так, что можно улучшить. Курс не делает персонального код-ревью вашего проекта ни в одном тарифе — только автоматическая самопроверка тестами.

## Компьютер и файлы

**Файл** — то, что открывается двойным кликом: документ, картинка, страница сайта. У каждого файла есть расширение — буквы после точки в конце имени (`.html`, `.txt`, `.md`), которые определяют, чем файл открывается.

**Создать текстовый файл (Windows)** — щёлкните правой кнопкой мыши по пустому месту на рабочем столе или в папке → «Создать» → «Текстовый документ». Откроется в Блокноте. Это не Word — сохранённый файл не будет `.docx`.

**Открыть файл для редактирования, а не для просмотра** — щёлкните по файлу **правой** кнопкой мыши → «Открыть с помощью» → «Блокнот» (или другой текстовый редактор). Обычный двойной клик по `.html`-файлу откроет его в браузере, а не даст редактировать текст внутри.

**Расширение `.md`** — обычный текстовый файл, просто с другим расширением (Markdown — способ форматирования текста). Создаётся и открывается так же, как `.txt`.

**«Рабочий стол» — два разных значения на этом сайте.** (1) Рабочий стол Windows/macOS — экран с иконками, куда можно сохранять файлы. (2) «Рабочий стол ассистента» — образное выражение для контекста (см. выше), не имеет отношения к экрану компьютера. Где встречается слово без уточнения — обычно понятно по смыслу фразы, но если сомневаетесь: инструкция «создайте папку на рабочем столе» — про экран компьютера.

**F5** — клавиша в верхнем ряду клавиатуры, обновляет открытую страницу браузера с диска. Не удаляет и не ломает ничего.

**F12** — клавиша, открывает встроенную панель инструментов браузера для разработчиков (внизу или сбоку экрана). Ничего не устанавливает и не ломает — это часть самого браузера, есть в каждом. Внутри есть вкладки Console (ошибки страницы) и Network (что сайт отправляет и получает).

**Ctrl+C (в терминале)** — безопасно останавливает выполняющуюся команду, ничего не удаляет и не портит.

## Сайты, HTML и оформление

**HTML** — язык разметки веб-страниц: текст с пометками, что где показывать (заголовок, кнопка, абзац). Не нужно уметь писать HTML самим — ассистент его пишет, вам нужно только копировать готовый код в файл.

**CSS, «стили»** — правила оформления страницы: цвета, шрифты, отступы. Как и HTML, пишется ассистентом — вам достаточно знать, что это слово означает «как страница выглядит», не «как она работает».

**Библиотека, «сторонняя библиотека»** — чужой готовый код, который использует ваш проект вместо того, чтобы писать всё с нуля. Фраза «без сторонних библиотек» в промптах — инструкция для ассистента, не для вас: значит «сделай максимально простым способом, без лишних подключений».

**Зависимость** — то же самое, что библиотека: чужой код, от которого зависит ваш проект.

**Lorem ipsum** — стандартный бессмысленный «текст-заполнитель», которым дизайнеры и разработчики временно занимают место, где потом будет настоящий текст. Если видите такой текст на сайте — это забытая заглушка, надо заменить на реальный.

**Закомментированный код** — строки кода, которые специально «выключены» (не выполняются), но остались в файле как черновик или заметка. В отличие от Word, здесь «комментарий» — это часть самого кода, а не отдельная пометка на полях.

## Терминал, сервер, публикация

**Терминал (командная строка)** — окно, куда печатают текстовые команды вместо кликов мышкой. Не отдельная программа для установки — она уже есть в Windows/macOS, открывается через поиск «Терминал» (или PowerShell). Подробно — День 5 «Полной».

**Node.js** — программа, которая нужна компьютеру, чтобы понимать команды вроде `npm`. Ставится один раз с официального сайта nodejs.org, дальше не требует внимания.

**npm** — программа для установки зависимостей (устанавливается вместе с Node.js). `npm install` — разово ставит нужные библиотеки проекта. `npm run dev` — запускает уже готовый проект локально.

**Порт** — «адрес» внутри вашего компьютера, по которому запущенный проект доступен в браузере (например `localhost:3000`). Сообщение «порт занят» значит, что проект уже запущен в другом окне терминала.

**Сервер** — просто чужой постоянно включённый компьютер в интернете, который держит ваш сайт или бота доступным. Не нужно ничего покупать физически — сервис публикации (см. ниже) предоставляет его за вас.

**Сервис публикации** — сайт, который берёт готовый проект и даёт ему адрес в интернете. В курсе для простых сайтов подойдёт, например, Netlify (netlify.com, есть перетаскивание папки без регистрации на первый раз) или Vercel (vercel.com); для проектов с базой данных нужна регистрация через GitHub.

**Сервис баз данных** — отдельный сайт, который хранит данные вашего проекта (заявки, записи) и даёт к ним доступ по интернету. Регистрация там отдельная от сервиса публикации.

## Git и репозиторий (со Дня 6 «Полной»)

**Git** — программа, которая запоминает состояния папки проекта во времени («точки возврата»), чтобы можно было вернуться к рабочей версии.

**Репозиторий** — папка проекта, за которой следит Git; хранит всю историю точек возврата.

**GitHub** — сайт (github.com, не программа на компьютере), где репозиторий хранится в интернете как резервная копия.

**Коммит, «точка возврата»** — сохранённое состояние всех файлов проекта в конкретный момент, с подписью.

**Main** — стандартное имя основной линии разработки в репозитории; создаётся автоматически, отдельно называть его не нужно.

**Origin** — имя связи между репозиторием на вашем компьютере и его копией на GitHub. Не логин и не название проекта — просто техническая метка.

**Хэш коммита** — короткий код из букв и цифр (например `a1b2c3d`), который однозначно называет конкретную точку возврата. Смотрите его командой `git log --oneline`, копируете оттуда — придумывать самим не нужно.

## Секреты и `.env`

**Секрет, ключ доступа** — пароль или код, который даёт программе доступ к чужому сервису (базе данных, ИИ-ассистенту). Утечка ключа — не абстрактная угроза, а реальный счёт на чужие траты.

**Файл `.env`** — обычный текстовый файл внутри папки проекта (рядом с `index.html`), где хранятся секреты отдельно от кода. Имя специально начинается с точки — это нормально, такие имена файлов существуют. Создаётся так же, как любой текстовый файл (см. выше), просто без текста после точки в названии.

**Переменная окружения** — значение, которое лежит в `.env`, а в коде на него только ссылаются по имени, не вписывая сам секрет. Было в коде: `const apiKey = "sk-abc123realkey"`. Стало: `const apiKey = process.env.API_KEY` — сам ключ остаётся только в `.env`.

**`.gitignore`** — файл-список того, что Git должен игнорировать и никогда не отправлять на GitHub. Обязательно должен содержать `.env`, иначе секреты попадут в открытый доступ.

## Деньги и юридическое

**API-ключ** — код доступа для программного использования ИИ-ассистента (не через обычный чат). Нужен только для Модуля 7 продвинутого трека — не для основного курса.

**ИП (индивидуальный предприниматель), юридическое лицо** — официально зарегистрированный статус для ведения бизнеса. У курса «Словокод» на данный момент их нет — это личный проект физического лица, оплата идёт напрямую человеку, без чека от организации. Подробности и что это значит для вас — в [оферте](/docs/legal/oferta).
