title: Наши шаблоны
---

Оригинальные файлы, которые мы готовим сами. Свободно используйте их в своих
проектах — они спроектированы так, чтобы быть максимально короткими и сразу
полезными, без «воды».

### [CLAUDE.md — стартовый шаблон](pathname:///templates/CLAUDE.md.example)
**Требует Claude Code · поток «Практик» / «Инженер»** (файл, откроется в новой вкладке)

Компактный файл правил проекта (команды, соглашения, зоны «не трогать»,
критерий готовности задачи) — скопируйте в корень своего проекта и адаптируйте.
Разбирается в модулях [M1](/docs/modules/module-1-claude-code) и
[«Токены, память и контекст»](/docs/modules/module-2t-tokeny-pamyat-kontekst).

### [Набор memory-bank](pathname:///templates/memory-bank/README.md)
**Требует Claude Code · поток «Практик» / «Инженер»** (файл, откроется в новой вкладке)

Пять ролевых markdown-файлов (`productContext`, `activeContext`, `decisionLog`,
`progress`, `systemPatterns`) — практика, вдохновлённая проектом
[RooFlow](https://github.com/GreatScottyMac/RooFlow) (подробнее — в разделе
[«Открытое сообщество»](/docs/resources/soobshchestvo)), адаптированная под
работу с Claude Code. Подробный разбор — в модуле
[«Токены, память и контекст»](/docs/modules/module-2t-tokeny-pamyat-kontekst).

### [Стартовая библиотека промптов](pathname:///templates/biblioteka-promptov.md)
**Подходит любому потоку, включая «Старт»** (файл, откроется в новой вкладке)

Каркасы промптов на каждый день по темам курса: письма и анализ документов,
поиск и исправление багов, код-ревью, регулярные проверки данных, очистка
таблиц, исследовательские отчёты, обновление memory-bank. Не готовые ответы —
шаблоны, которые вы подстраиваете под свою задачу.

:::tip[Пополняйте сами]
Лучшая библиотека промптов — та, которую вы ведёте сами: как только находите
формулировку, которая стабильно работает, — сохраняйте её рядом с этими
шаблонами.
:::
