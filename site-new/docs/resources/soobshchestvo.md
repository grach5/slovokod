Проекты с открытым исходным кодом — не от Anthropic, но заслуживающие внимания.
Мы не отвечаем за их точность и актуальность, но описываем своими словами, зачем
каждый из них может пригодиться в контексте курса.

### [Learn Prompting](https://github.com/trigaten/Learn_Prompting)
Одна из самых полных открытых баз по промпт-инжинирингу: от основ до
продвинутых тем вроде «prompt hacking» и уязвимостей промптов. Хорошее чтение
после модуля [M0](/docs/modules/module-0-osnovy-promptinga), когда хочется
углубиться за рамки курса.

### [awesome-claude-prompts](https://github.com/langgptai/awesome-claude-prompts)
Куратируемая коллекция промптов под Claude по разным сценариям использования —
удобно смотреть как источник вдохновения, а не копировать один в один: хороший
промпт почти всегда нужно адаптировать под свою задачу (см. модуль
[M0](/docs/modules/module-0-osnovy-promptinga)).

### [RooFlow](https://github.com/GreatScottyMac/RooFlow)
Проект для расширения Roo Code (AI-агента для VS Code), который ввёл паттерн
«memory bank» — набор ролевых markdown-файлов, которые агент читает и
обновляет, чтобы не терять контекст между сессиями, плюс компактные системные
инструкции вместо раздутых. Именно этот паттерн лёг в основу нашего модуля
[«Токены, память и контекст»](/docs/modules/module-2t-tokeny-pamyat-kontekst) —
мы не используем сам RooFlow, а адаптируем идею под Claude Code.

:::note[Проверяйте лицензии]
Прежде чем использовать код или крупные фрагменты текста из стороннего
open-source репозитория в коммерческом проекте — проверьте его лицензию. Это
относится к любому репозиторию, не только перечисленным здесь.
:::
