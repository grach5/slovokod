Проекты с открытым исходным кодом — не от Anthropic, но заслуживающие внимания.
Открытый исходный код — это когда все файлы проекта выложены в открытом доступе
и их может бесплатно посмотреть или скачать кто угодно. Мы не отвечаем за их
точность и актуальность, но описываем своими словами, зачем каждый из них может
пригодиться в контексте курса.

Ссылки ниже ведут на GitHub — сайт, где разработчики бесплатно хранят код и
документацию. Открывать там ничего не нужно, регистрация и установка не
требуются — просто почитайте README.

### [Learn Prompting](https://github.com/trigaten/Learn_Prompting)
Одна из самых полных открытых баз по промпт-инжинирингу: от основ до
продвинутых тем вроде «prompt hacking» (приёмы обхода ограничений модели — тема
для защиты систем, не для незаконного взлома) и уязвимостей промптов. Хорошее
чтение после модуля [«Основы промптинга»](/docs/modules/module-0-osnovy-promptinga),
когда хочется углубиться за рамки курса.

### [awesome-claude-prompts](https://github.com/langgptai/awesome-claude-prompts)
Куратируемая коллекция промптов под Claude по разным сценариям использования —
удобно смотреть как источник вдохновения, а не копировать один в один: хороший
промпт почти всегда нужно адаптировать под свою задачу (см. модуль
[«Основы промптинга»](/docs/modules/module-0-osnovy-promptinga)).

### [RooFlow](https://github.com/GreatScottyMac/RooFlow)
Проект для расширения Roo Code (AI-агента для VS Code — популярного бесплатного
редактора кода), который одним из первых предложил рабочую реализацию паттерна
«memory bank» (изначально описанного сообществом Cline) для Roo Code — набор
ролевых markdown-файлов, которые агент читает и обновляет, чтобы не терять
контекст между сессиями, плюс компактные системные инструкции (правила, которые
агент получает один раз в начале работы, до вашего первого сообщения) вместо
раздутых. Именно этот паттерн лёг в основу нашего модуля
[«Токены, память и контекст»](/docs/modules/module-2t-tokeny-pamyat-kontekst) —
мы не используем сам RooFlow, а адаптируем идею под Claude.

:::note[Проверяйте лицензии]
Прежде чем использовать код или крупные фрагменты текста из стороннего
open-source репозитория в коммерческом проекте — проверьте его лицензию.
Лицензия — это файл LICENSE в репозитории (обычно виден в списке файлов на
GitHub). Он описывает, что можно делать с кодом: например, MIT и Apache
разрешают почти всё, а без файла LICENSE использовать код нельзя вообще. Это
относится к любому репозиторию, не только перечисленным здесь.
:::
