_Часть раздела [«Ресурсы»](./resursy)_

Материалы напрямую от Anthropic, разработчика Claude. Это первая из трёх
категорий раздела «Ресурсы» — рядом ещё [«Открытые проекты»](./soobshchestvo)
и [«Наши шаблоны»](./shablony). Начинайте с этой категории, когда нужна
точность от первоисточника — в отличие от «Открытых проектов», где
материалы уже прошли через чужую интерпретацию.

Большинство ссылок ниже ведут на GitHub — внешний сайт для хранения кода, на
английском языке; регистрация не нужна, чтобы просто посмотреть материалы.

### [Claude Code](https://github.com/anthropics/claude-code)
Репозиторий (хранилище кода на GitHub) CLI-агента (CLI — интерфейс командной
строки, т.е. терминал) для разработки: issue-трекер (список задач и багов),
документация, примеры.
Первый источник правды для модулей [M1](/docs/modules/module-1-claude-code)
и [M2](/docs/modules/module-2-avtomatizaciya-agenty).

### [Claude Cookbooks](https://github.com/anthropics/claude-cookbooks)
Официальный сборник рецептов по построению приложений на Claude: агенты, RAG
(Retrieval-Augmented Generation — поиск нужных данных перед ответом модели),
tool use, работа со Skills (навыками). Полезно на модуле
[M7 — Claude API / SDK](/docs/modules/module-7-api-sdk) (Продвинутый трек),
когда нужен готовый паттерн решения, а не теория с нуля.

### [Agent Skills](https://github.com/anthropics/skills)
Официальный репозиторий «Agent Skills» — переиспользуемых пакетов инструкций,
которые можно подключать к Claude Code как готовые расширения (плагины) —
Anthropic ведёт для них каталог (маркетплейс). Это не то же самое, что
MCP-коннекторы из M8: Skills не требуют внешнего сервиса, это просто набор
инструкций и скриптов. Хорошая отправная точка для модуля
[M8 — Интеграции и экосистема](/docs/modules/module-8-integracii):
прежде чем писать свою интеграцию с нуля, проверьте, нет ли
готового навыка.

### [Интерактивный туториал по промпт-инжинирингу](https://github.com/anthropics/prompt-eng-interactive-tutorial)
Официальный обучающий курс Anthropic из девяти глав с практическими
упражнениями (открываются по главам — ищите в каждой папке ссылку
«Open in Colab»). Хорошее дополнение к модулю
[M0 — Основы промптинга](/docs/modules/module-0-osnovy-promptinga) — от
повторения основ до более продвинутых техник, которые в модуле не
разбираются.

### [Документация Claude API / SDK](https://docs.claude.com/)
Справочник по Messages API, потоковой передаче, tool use, prompt caching,
Agent SDK и мультимодальности — основной источник для модуля
[M7](/docs/modules/module-7-api-sdk).

:::note[Актуальность ссылок]
Названия и адреса официальных ресурсов Anthropic могут меняться. Если ссылка в
этом разделе устарела — считайте это поводом поискать актуальную версию: для
