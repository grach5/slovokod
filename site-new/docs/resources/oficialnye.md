---

Материалы напрямую от Anthropic, разработчика Claude. Начинайте с них, когда
нужна точность, а не чужая интерпретация.

### [Claude Code](https://github.com/anthropics/claude-code)
Репозиторий CLI-агента для разработки: issue-трекер, документация, примеры.
Первый источник правды для модулей [M1](/docs/modules/module-1-claude-code) и
[M2](/docs/modules/module-2-avtomatizaciya-agenty).

### [Claude Cookbooks](https://github.com/anthropics/claude-cookbooks)
Официальный сборник рецептов по построению приложений на Claude: агенты, RAG,
tool use, работа со Skills. Полезно на модуле
[M7 — Claude API / SDK](/docs/modules/module-7-api-sdk), когда нужен готовый
паттерн решения, а не теория с нуля.

### [Anthropic Skills](https://github.com/anthropics/skills)
Официальный репозиторий «Agent Skills» — переиспользуемых пакетов инструкций и
инструментов, которые можно подключать к Claude Code как плагины/маркетплейс
навыков. Хорошая отправная точка для модуля
[M8 — Интеграции и экосистема](/docs/modules/module-8-integracii): прежде чем
писать свою интеграцию с нуля, проверьте, нет ли готового навыка.

### [Интерактивный туториал по промпт-инжинирингу](https://github.com/anthropics/prompt-eng-interactive-tutorial)
Официальный обучающий курс Anthropic из девяти глав с практическими
упражнениями прямо в браузере. Хорошее дополнение к модулю
[M0 — Основы промптинга](/docs/modules/module-0-osnovy-promptinga), если
хочется больше практики того же уровня.

### Документация Claude API / SDK
Справочник по Messages API, потоковой передаче, tool use, prompt caching,
Agent SDK и мультимодальности — основной источник для модуля
[M7](/docs/modules/module-7-api-sdk) на потоке «Инженер».

:::note[Актуальность ссылок]
Названия и адреса официальных ресурсов Anthropic могут меняться. Если ссылка в
этом разделе устарела — считайте это поводом поискать актуальную версию в
