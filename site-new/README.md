# Словокод — сайт

Сайт курса построен на [Docusaurus](https://docusaurus.io/). Контент — в `docs/`
(треки «База»/«Полная», модули Продвинутого трека, ресурсы, руководства, юр.
черновики) и `src/pages/` (маркетинговые страницы: главная, программа, примеры,
контакты).

## Установка

```bash
npm install
```

## Локальная разработка

```bash
npm run start
```

Запускает локальный сервер с горячей перезагрузкой на порт по умолчанию (3000)
или на `--port <N>`.

## Сборка

```bash
npm run build
```

Генерирует статические файлы в `build/` — их можно разместить на любом хостинге
статики (GitHub Pages, Netlify, Vercel и т.д.).

## Структура контента

- `docs/baza/` — трек «База» (5 дней)
- `docs/polnaya/` — трек «Полная» (14 дней)
- `docs/modules/` — Продвинутый трек, бонус (M0–M9 + M2.5)
- `docs/resources/` — раздел «Ресурсы»: каталог типов проектов, работа с
  заказчиками, официальные материалы, открытое сообщество, наши шаблоны
- `docs/guides/` — отдельные руководства (например, «Вайбкодинг»)
- `docs/legal/` — черновики оферты и политики данных
- `static/templates/` — скачиваемые шаблоны (банки промптов, CLAUDE.md,
  memory-bank), на которые ссылается раздел «Ресурсы»
- `src/pages/` — маркетинговые страницы (главная, программа, примеры, контакты)
