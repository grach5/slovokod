# Шаблон memory-bank

Набор из пяти ролевых markdown-файлов — практика, вдохновлённая проектом
[RooFlow](https://github.com/GreatScottyMac/RooFlow) для Roo Code, адаптированная
для любого длительного проекта с ИИ-агентом (в том числе Claude Code).

Идея: вместо одного разрастающегося файла заметок или надежды на память модели —
пять файлов с чёткой ролью каждого. В начале сессии агент читает нужные файлы;
в конце значимой сессии — вы (или агент по команде) их обновляете.

## Файлы

| Файл | Роль | Обновляется |
|---|---|---|
| `productContext.md` | Что за проект, для кого, зачем — общая картина | Редко: при смене цели проекта |
| `activeContext.md` | Что делаем прямо сейчас, какие вопросы открыты | Каждую сессию |
| `decisionLog.md` | Архитектурные решения и ПОЧЕМУ именно так | При каждом значимом решении |
| `progress.md` | Что сделано, что в работе, что дальше | Каждую сессию |
| `systemPatterns.md` | Повторяющиеся паттерны кода/архитектуры проекта | По мере обнаружения |

## Как использовать

1. Скопируйте папку `memory-bank/` в корень своего проекта.
2. Заполните `productContext.md` один раз в начале.
3. В начале каждой сессии с ИИ-агентом — попросите прочитать
   `activeContext.md` и `progress.md`.
4. В конце сессии — попросите агента (или сделайте сами) обновить
   `activeContext.md` и `progress.md`, а при архитектурном решении — добавить
   запись в `decisionLog.md`.

Подробный разбор паттерна — в модуле «Токены, память и контекст» курса
«Академия Claude».
